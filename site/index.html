A

채팅 우선 · 모델 선택 · 메모리 Chat-first · model picker · memory

채널 첫 화면이 바로 새 대화예요. 에이전트 없이도 모델만 연결하면 기본 채팅이 되고, 입력창에서 모델과 추론 수준을 골라요. 에이전트는 @이름으로 부를 때만 쓰이고, 기본 채팅은 메인 메모리를, 에이전트는 각자 메모리를 가져요. Every channel opens on a fresh chat. Connect a model and chat right away, no agent needed; pick the model and reasoning level from the composer. Agents join only when you @mention them. The default chat keeps a main memory, each agent its own.

네이티브 하네스 · 내장 툴 29종 Native harness · 29 built-in tools

Anthropic, Gemini, OpenAI 호환, Ollama 모델이 Argos 자체 툴 루프에서 일정·할 일·파일·셸 툴을 써요. render_artifact로 그림을 그리고, 연속 툴 호출은 한 줄로 접히고, 삭제·명령 실행은 승인 카드에서 기다려요. Anthropic, Gemini, OpenAI-compatible and Ollama models run Argos' own tool loop with schedule, task, file and shell tools. render_artifact draws inline, consecutive tool calls fold into one line, and deletes or commands wait on an approval card.

워크스페이스 · 로컬 폴더 · LMS 검색 Workspace · local folders · LMS search

채널마다 파일을 올리거나 내 컴퓨터 폴더를 바로 연결해요. 올린 파일과 LMS 강의 자료는 SQLite FTS5로 색인되어 search_knowledge와 워크스페이스 패널에서 찾을 수 있어요. Upload files to a channel or link a folder on your Mac. Uploads and LMS course materials are indexed with SQLite FTS5, searchable from search_knowledge and the workspace panel.

03 — 설치Install

세 단계면 시작해요 Up and running in three steps

  1. 1

    내려받기Download

    최신 릴리스에서 Argos_<버전>_aarch64.dmg를 받아요. Get Argos_<version>_aarch64.dmg from the latest release.

  2. 2

    처음 열기First launch

    응용 프로그램으로 옮긴 뒤 처음 한 번은 우클릭 → 열기로 열어요(애드혹 서명). Drag it into Applications, then right-click → Open the first time (ad-hoc signed).

  3. 3

    연결하기Connect

    환영 화면에서 언어를 고르고, 모델과 에이전트 도구(MCP·스킬)를 한 번에 연결해요. Pick a language on the welcome screen and connect models and agent tools (MCP + skill) in one go.
