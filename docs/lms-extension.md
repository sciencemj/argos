# LearningX LMS 확장 프로그램 연결

로그인된 브라우저 탭에서 학습 정보를 읽어 이 Mac의 Argos에 전달하는 개발용 Chrome/Edge 확장 프로그램입니다. 현재 고려대 `lms.korea.ac.kr`, `mylms.korea.ac.kr`를 지원합니다.

## 설치와 연결

1. 새 코드의 Argos 서버와 프런트엔드를 실행합니다. 기존 설치 앱은 이 변경을 포함한 빌드가 필요합니다.
2. Chrome의 `chrome://extensions`에서 **개발자 모드 → 압축해제된 확장 프로그램 로드**를 선택합니다. Edge는 `edge://extensions`입니다.
3. 저장소의 `integrations/learningx-extension` 폴더를 선택합니다.
4. Argos **설정 → 연결 → LearningX LMS → 연결 코드 발급**을 누릅니다.
5. 확장 프로그램 팝업에서 Argos 주소와 연결 코드를 입력하고 **연결 저장**을 누릅니다.
   - 설치 앱: `http://127.0.0.1:8000`
   - 개발 서버: `http://127.0.0.1:8100`
6. 브라우저에서 고려대 LMS에 직접 로그인한 뒤 **지금 수집**을 누릅니다.

자동 수집을 켜면 LMS 페이지 로딩 완료 시, 또는 15분마다 열린 LMS 탭에서 수집합니다. 성공한 수집 후 5분 동안 페이지 이동으로 인한 반복 수집을 건너뜁니다. 브라우저·Argos가 실행되고 LMS 탭이 열려 있어야 합니다. Chrome이 잠자기 상태면 갱신이 지연될 수 있습니다.

## 가져오는 정보

- 수강 중인 과목별 채널을 `LearningX` 영역에 만듭니다. 동일한 과목 이름·다른 계정을 구별하는 식별자가 채널 이름에 붙습니다.
- **과제**: 제목, 설명, 마감일, 제출 상태를 할 일에 저장합니다. 제출 상태는 설명에 표시하며 Argos의 완료 상태를 자동 변경하지 않습니다.
- **공지·최근 활동·받은 메시지 요약**: 과목 피드 또는 별도 알림·메시지 채널에 저장합니다. 메시지 전체 대화나 휴대폰 푸시 이력은 수집하지 않습니다.
- **출결**: 과목의 출결 현황 화면에서 **현재 출결 표 가져오기**를 누르면 현재 표를 피드에 저장합니다. `th`에 출결/출석이 표시된 HTML 표가 대상입니다. iframe·외부 도메인·표가 아닌 화면은 첫 버전에서 지원하지 않습니다. 출결 API 자동 조회나 출석 처리는 하지 않습니다.
- **주차학습 자료**: 팝업에서 **주차학습 자료도 저장**을 켜고 **연결 저장**을 누르면, 수강 과목의 Canvas 모듈에서 `File` 항목을 조회합니다. 자료 제목·주차/단원·LMS 링크를 과목 피드에 기록하고 파일을 기존 Argos 첨부파일 저장소에 보관합니다. 피드에서 열거나 내려받을 수 있습니다. 기본값은 꺼짐이며 기존 연결에는 자동으로 켜지지 않습니다.

주차학습 파일은 개별 파일 API를 사용하므로 과목 전체 `/files` 목록 조회 권한이 없어도 수집할 수 있습니다. 파일 ID·이름·크기·수정일이 같은 자료는 다시 다운로드하지 않습니다. 변경된 자료는 같은 피드 항목의 첨부를 교체하며 이전 파일을 제거합니다. 로컬 파일이 없어진 경우에도 다시 저장합니다. 제목이나 주차 이름만 변경됐으면 파일을 다시 내려받지 않습니다. 파일 저장 실패 시 자료 목록은 유지되고 팝업에 파일별 실패가 표시되며 다음 수집에서 재시도합니다.

자료는 **파일당 최대 25MB, 한 번에 최대 50개** 저장합니다. LMS와 같은 출처의 직접 다운로드 및 고려대가 사용하는 네이버 클라우드 저장소를 지원합니다. 저장소 자료는 Canvas `GET /api/v1/files/:id/public_url`에서 서명된 주소를 받아 리다이렉트를 거치지 않고 다운로드합니다. Argos는 HTTPS의 `kr.object.gov-ncloudstorage.com/korea-canvas-contents/` 경로만 허용하며 URL 경로의 파일 ID도 확인합니다. 다른 저장소·추가 리다이렉트는 허용하지 않습니다. 잠긴 자료·숨겨진 자료는 제외하고, 영상·외부 도구를 실행하지 않습니다. **강의자료실 게시판 첨부파일은 이번 구현에서 제외**하며 실제 첨부 경로를 확인한 뒤 별도 연동이 필요합니다.

동일한 항목은 반복 수집해도 중복 저장하지 않습니다. 원격 제목·설명·마감일 변경은 반영하고 Argos의 할 일 상태와 순서는 보존합니다. 원격 항목이 조회되지 않더라도 기존 데이터는 삭제하지 않습니다. 출결 표는 화면 URL별로 가장 최근에 가져온 상태를 유지합니다. 과목별 일부 조회가 실패하면 성공한 항목을 저장하고 팝업에 실패 범위를 표시합니다.

## 연결과 데이터 보관

학교 비밀번호·쿠키·LMS 토큰은 Argos로 보내지 않습니다. LMS 조회는 해당 탭 안에서 로그인 세션으로 GET 요청만 수행합니다. 출결·메시지 읽음 처리·과제 제출 요청은 하지 않습니다. 읽은 LMS 본문은 HTML에서 텍스트로 변환하고 Argos에서 Markdown 특수문자를 이스케이프합니다.

LMS 직접 다운로드는 브라우저 탭에서 수행하고 파일 내용을 인증한 로컬 Argos에 전송합니다. 네이버 클라우드 자료는 파일 전용 서명 주소만 로컬 Argos에 전달해 Argos가 직접 받습니다. 저장소 요청에는 학교 쿠키·학교/Argos 인증 헤더를 보내지 않으며 환경의 프록시도 사용하지 않습니다. 서명 주소는 요청 처리 중에만 사용하고 DB·활동 로그·확장 프로그램 상태에 저장하지 않습니다. 데스크톱의 HTTP 요청 로그에서도 저장소 URL의 쿼리를 제거합니다. 파일명은 표시용으로 정리하고 실제 저장 경로는 Argos의 새 첨부파일 ID로 결정합니다. 파일 저장은 자료 목록의 최신 버전과 일치해야 하며, 크기가 다르거나 로그인 HTML이면 저장하지 않습니다.

확장 프로그램에는 LMS 도메인 접근, 스크립트 실행, 로컬 저장소, 갱신 타이머, `127.0.0.1` 연결 권한만 있습니다. 로컬 서버 주소는 `http://127.0.0.1:포트`로 제한합니다. LMS 데이터를 로컬 Argos에 저장한 이후에는 기존 Argos 데이터와 동일하게 백업 및 선택한 에이전트의 접근 대상이 됩니다.

Argos 연결 코드는 확장 프로그램의 신뢰된 화면에서만 접근 가능한 로컬 저장소에 보관합니다. 서버에는 코드의 SHA-256 해시만 저장하며 활동 로그·실시간 이벤트에는 코드를 남기지 않습니다. 재발급·Argos 측 연결 해제 시 기존 코드가 폐기됩니다. 확장 프로그램의 연결 해제는 브라우저에 저장된 코드와 타이머를 삭제합니다. 어느 쪽을 해제해도 이미 가져온 학습 정보는 남습니다.

## 검증과 남은 확인

```sh
cd backend
uv run pytest tests/test_lms.py -q
cd ../frontend
bunx vitest run src/lms-extension.test.ts
```

자동화 검증은 가짜 Canvas 응답과 임시 Argos DB를 사용합니다. 주차자료의 목록 조회·누락된 모듈 항목 별도 조회·파일 접근 제한·계정 변경·크기 제한·부분 실패, 첨부 저장·중복 방지·수정 교체·파일 누락 복구를 검증합니다.

2026-10-08 실제 고려대 로그인 세션에서 모듈 목록과 개별 파일 API 조회를 확인했습니다. 전체 파일 목록 API는 권한 오류였지만 개별 파일 API는 성공했습니다. 비즈니스애널리틱스II의 PDF 한 개(350,665 bytes, 16페이지)를 임시 Argos 서버에 저장하고 원본 응답과 SHA-256 일치 및 반복 수집 시 다운로드·첨부 중복 없음까지 검증했습니다. [검증 기록](lms-materials-verification.md). 설치된 Argos 앱에는 새 코드 적용이 필요합니다. 강의자료실 첨부와 출결 표의 실제 HTML 구조는 추가 확인이 필요합니다.

첫 실사용 확인: 개발 서버로 연결 → 로그인 → 수집 → 과목 채널·할 일 확인 → 한 번 더 수집해 중복 없음 확인 → 출결 화면에서 표 가져오기 → 연결 코드 재발급 후 기존 확장 프로그램 수집이 거절되는지 확인.

공식 근거: [Chrome 콘텐츠 스크립트](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts), [확장 프로그램의 네트워크 요청](https://developer.chrome.com/docs/extensions/develop/concepts/network-requests), [Canvas 과제 API](https://developerdocs.instructure.com/services/canvas/resources/assignments), [고려대 학습자 매뉴얼](https://digital.korea.ac.kr/ic/LMS_manual_student.do).
