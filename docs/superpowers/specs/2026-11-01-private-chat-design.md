# 비공개 대화 (Phase 21 설계)

2026-11-01 사용자 요청. 모델 연결(Phase 20, `docs/superpowers/specs/2026-10-31-model-providers-design.md`)의
위치 구분(`device`/`network`/`cloud`)을 쓴다.

## 목표

밖으로 새면 안 되는 업무 정보(붙여 넣은 글, PDF·문서·이미지 파일)를 넣고 로컬 모델에게 묻는 일회성 대화.
두 가지가 핵심이다: **내용이 클라우드로 나가지 않는다**, **Argos가 어디에도 기록하지 않는다**.

성공 기준:

- 로컬 모델 에이전트의 DM 오른쪽 위에 유령 버튼이 있고, 누르면 누른 자리에서 원이 퍼지며 비공개 화면으로 바뀐다.
  다시 누르면 같은 방식으로 일반 DM으로 돌아온다.
- 비공개 화면에서 글과 파일을 보내면 그 에이전트의 모델이 스트리밍으로 답한다.
- 비공개 대화 중·후에 Argos DB(`message`, `agent_run`, `activity_log`, `attachment` 등), `data_dir` 아래 파일,
  서비스 로그 어디에도 대화 내용·파일 내용·파일 이름이 남지 않는다(테스트로 확인).
- 비공개 대화는 앱이 켜져 있는 동안 유지된다: 일반 DM으로 돌아갔다 다시 들어와도, 다른 화면에 갔다 와도 그대로다.
  데스크톱 앱 창을 닫아도(숨김) 남는다. 앱을 끄거나 페이지를 새로고침하면 사라진다.
- 클라우드 위치이거나 로컬 모델이 아닌 에이전트의 DM에는 유령 버튼이 없다.

## 범위 밖

- 음성 비서, 빠른 입력 창(`⌘⇧Space`)과 일반 채널의 비공개 모드.
- Argos 도구(MCP)·스킬·웹 검색·코딩 모드 — 비공개 대화는 순수 대화만.
- 비공개 대화 내보내기·저장·복사 버튼(브라우저 기본 복사는 막지 않음).
- 원격 모델 서버(Ollama)의 로그·메모리, macOS 스왑까지의 보장(안내 문구로만 알림).

## 사용자가 정한 것

- 진입: DM 오른쪽 위 유령 모양 버튼으로 전환. 전환 시 누른 지점에서 퍼지는 원(파동) 애니메이션.
- 모양: 비공개는 항상 지금보다 어둡게. 라이트 테마 → 다크 팔레트, 다크 테마 → 더 깊은 검정
  (시안: `.superpowers/brainstorm/98173-1793463039/content/private-mode.html`의 A, `private-dark.html`의 A).
- 보관: 앱이 켜져 있는 동안만.
- 파일 첨부 지원.
- 클라우드 에이전트(Claude·Codex·Hermes, 클라우드 위치 연결의 에이전트)의 DM에는 버튼이 보이지 않는다.

## 내 판단 (사용자 확인 전)

- **버튼이 보이는 조건**: 에이전트 백엔드가 `ollama`(모델 연결)이고, 그 에이전트가 쓰는 연결의 위치가 `device`
  또는 `network`이고, 실제로 쓰일 모델(`agent.model or classifier_title_model or classifier_model`, Phase 20의
  연결 선택 규칙 그대로)이 이름상 Ollama 클라우드 모델(`-cloud`로 끝나거나 `:cloud` 태그)이 아닐 때. 서버가
  `AgentOut.private_ok: bool`로 계산해 내려 준다(목록 화면에서 네트워크 호출 없이).
- **서버는 요청마다 실제로 확인**: 비공개 엔드포인트는 위 조건을 다시 보고, 연결 종류가 `ollama`면 `/api/show`로 그
  모델의 `remote_host`를 확인해 클라우드면 422(이름을 바꿔 복사한 클라우드 모델까지 막음). 확인 실패도 거부.
  OpenAI 호환 연결은 위치(`device`/`network`)만으로 허용한다: 그 서버가 다시 클라우드로 넘기는지는 알 수 없고,
  그런 서버는 사용자가 연결 설정에서 "클라우드로" 표시하면 빠진다.
- **대화 상태는 화면 메모리에만**: React 상태(전역 store, 예: 모듈 수준 Map 또는 zustand 같은 기존 패턴)에 에이전트별로
  둔다. `localStorage`·`sessionStorage`·IndexedDB·서비스 워커 캐시·React Query 캐시 영속화에 넣지 않는다.
- **서버는 기록 없이 중계만**: 새 엔드포인트 `POST /api/v1/agents/{name}/private`(요청 하나 = 한 턴, 이전 대화를
  JSON 본문에 실어 보냄, 응답은 스트리밍). multipart는 쓰지 않는다: Starlette가 1MB 넘는 업로드를 시스템 임시
  폴더 파일로 내리기 때문. 파일은 별도 엔드포인트 `POST /api/v1/agents/{name}/private/files`(JSON, base64)로 한
  번만 보내고, 서버가 메모리에서 처리한 결과(뽑은 글, 축소한 JPEG의 base64, 원본 PDF가 필요한 모델이면 그 base64)를
  돌려준다. 화면은 그 처리된 조각만 메모리에 들고 다음 턴부터는 조각을 대화와 함께 보낸다(원본 재업로드·재처리 없음).
  대화 전체 크기 상한은 화면에서 `attachment_max_mb`의 4배(넘으면 "대화가 너무 길어요 · 지우고 새로 시작해 주세요"). `services` 쓰기 경로를 타지 않는다(이 기능만의 예외, decisions.md에 기록).
  `agent_run`·메시지·WS 이벤트·`activity_log` 없음. 예외 로그에는 예외 종류만, 요청 본문·모델 출력은 쓰지 않는다.
  uvicorn 접근 로그에는 경로만 남는다(본문 없음).
- **파일은 디스크에 안 씀**: 서버가 메모리(bytes)에서 종류 판별·HEIC→JPEG 변환·이미지 축소·PDF 글 추출을 한다.
  지금의 `attachments.py`(`_image`, `_pdf_text`, `_native_pdf`, `ImagePart.path`, HEIC는 `save_upload`에서만)는 경로
  기반이니 bytes를 받는 변형을 둔다. 임시 파일도 쓰지 않는다(테스트가 `data_dir`과 시스템 임시 폴더 둘 다 확인).
  파일 하나 크기 제한은 일반 첨부와 같은 `attachment_max_mb`.
- **어댑터 재사용 범위**: `OpenAICompatAdapter.stream`은 안에서 경로 기반 `split_attachments`를 부르므로 그대로 못 쓴다.
  비공개 엔드포인트가 메시지(시스템, 대화, 이미지 파트)를 직접 만들어 `providers.chat_client`로 스트리밍 요청한다.
  Ollama면 `reasoning_effort: "none"`. 연결 실패 문구는 `providers.unreachable_text`.
- **입력창**: 피드의 `Composer`는 파일을 넣자마자 `/attachments`에 업로드하므로(DB 행 + 파일) 모양만 본뜨고 파일 선택
  상태는 업로드하지 않는 새 구현으로 한다.
- **에이전트 설정은 그대로, 도구는 없음**: 그 에이전트의 시스템 프롬프트와 모델을 쓰고 도구는 주지 않는다.
  `build_context`는 쓰지 않고(DM에서는 정체성·시각·"Argos 도구를 써라"·답 언어 줄뿐), 비공개용 짧은 시스템 문맥을
  새로 둔다: 지금 시각과 답 언어 줄만(도구 안내 없음). 에이전트 시스템 프롬프트가 없으면(내장 `@local`) 그 짧은 문맥만.
- **로그 금지 범위**: 이 엔드포인트는 `log.exception`을 쓰지 않고(트레이스백에 지역 변수·본문이 실릴 수 있음) 예외
  종류 이름만 남긴다. 오류 문구에 `str(exc)`를 넣지 않는다(`runner.py`의 `f"{type}: {exc}"` 패턴을 따르지 않음).
  본문 검증 오류(pydantic)도 입력값을 담지 않은 고정 문구로 바꿔 돌려준다.
- **앱이 켜져 있는 동안 유지 — 페이지를 다시 불러오는 경로**: 데스크톱 앱의 `open_main(path)`(빠른 입력 창의 "메인에서
  열기")는 지금 `window.navigate`로 페이지를 새로 불러와 비공개 대화가 지워진다. 메인 창이 이미 앱을 띄우고 있으면
  이벤트를 보내 화면 안에서 라우팅하도록 바꾼다(`lib.rs` + 프런트 이벤트 리스너). 언어 바꾸기(`i18n.ts`의
  `location.reload()`)와 첫 시작 때의 이동은 그대로 두고 "앱을 다시 불러오면 사라짐"으로 본다.
- **일반 DM 기록과 분리**: 비공개 대화는 빈 상태로 시작하고 일반 DM 기록을 모델에 보내지 않는다. 반대로 비공개 내용도
  일반 DM으로 가지 않는다.
- **지우기**: 비공개 화면에 "대화 지우기" 버튼(즉시 메모리에서 삭제). 확인 대화상자 없이 바로.
- **답 중단**: 일반 DM처럼 중단 버튼으로 스트림을 끊는다(요청 취소 → 서버가 모델 요청 취소).
- **안내 문구**: 비공개 화면 상단 띠 "비공개 대화 · 이 기기와 내 네트워크의 모델만 쓰고, 앱을 끄면 사라져요".
  빈 화면에는 "여기서 나눈 대화는 어디에도 저장되지 않아요" 한 줄. 한계(원격 서버 메모리, 스왑) 안내는 넣지 않는다
  (사용자 결정 2026-11-01).
- **색**: 비공개용 토큰을 `index.css`에 추가한다(`--private-*`, 라이트/다크 각각). 라이트일 때 비공개 팔레트는 지금
  다크 토큰 값, 다크일 때는 더 어두운 값. 컴포넌트는 토큰만 쓴다.
- **애니메이션**: 비공개 레이어를 `clip-path: circle()`로 누른 지점에서 키우고(약 0.65초, ease-out), 같은 자리에서
  옅은 링이 퍼진다. 돌아갈 때는 반대로 줄어든다. `prefers-reduced-motion`이면 즉시 전환.
- **폰(Tailscale로 연 화면)**: 같은 화면이므로 그대로 동작한다. 폰 브라우저 탭을 닫으면 사라진다.

## 백엔드

- `AgentOut.private_ok: bool` (위 조건, `_agent_out`에서 계산; 연결 위치는 `providers.resolve`/`classifier_provider`,
  `*-cloud` 판정은 모델 이름이 `-cloud`로 끝나는지 또는 연결의 모델 목록 `remote` — 목록을 매번 부르지 않도록 이름 규칙으로).
- `POST /api/v1/agents/{name}/private/files`: JSON `{files: [{name, data_base64}]}` → 처리된 조각 목록
  (`{kind: "text"|"image"|"pdf", name, text?, data_base64?, mime?}`, 처리 못 한 파일은 "내용 읽기 불가" 글 조각).
- `POST /api/v1/agents/{name}/private`: JSON `{turns: [{role, text, parts: [조각]}]}`. 응답 `text/event-stream` 또는
  NDJSON(토큰 단위). 오류는 스트림 안에서 `{"error": "<한국어 문구>"}`.
- 이 엔드포인트의 함수들은 로거에 본문을 넘기지 않는다. 테스트가 caplog로 확인.

## 프런트엔드

- `pages/ChannelPage.tsx`의 `DMPage` 헤더 오른쪽에 유령 버튼(`agent.private_ok`일 때만). 아이콘은 인라인 SVG.
- 비공개 레이어 컴포넌트(새 파일, 예: `privateChat.tsx`): 입력창(글·파일), 스트리밍 답, 지우기, 중단. 기존
  `feed.tsx` 입력창·답 카드의 모양을 재사용하되 서버 저장 로직은 쓰지 않는다.
- 상태 store는 모듈 수준(앱 수명 동안 유지), 에이전트 id → 대화 배열 + 파일(메모리의 `File` 객체).
- 문구는 `tr()`/`tt`, 영어는 `en.ts`.

## 테스트

- 백엔드: 가짜 어댑터로 비공개 엔드포인트가 스트리밍하고, 끝난 뒤 DB의 모든 테이블 행 수가 그대로이며
  `data_dir`과 시스템 임시 폴더에 새 파일이 없고, caplog에 대화 글·파일 이름이 없음을 확인. 모델이 `remote_host`인
  Ollama 클라우드 모델(로컬 이름으로 복사한 경우 포함)이면 거부. 이미지·PDF·텍스트 첨부를 메모리에서 처리.
  `private_ok`가 클라우드 연결·`*-cloud` 모델·Claude 에이전트에서 false, 로컬 연결에서 true. 조건이 안 맞으면 422.
- 데스크톱: 메인 창이 이미 열려 있을 때 `open_main`이 페이지를 새로 불러오지 않고 화면 안에서 이동.
- 프런트: 버튼 표시 조건, 전환 후 비공개 레이어 표시, 메시지 보내기(가짜 스트림), 일반 DM ↔ 비공개 왕복 후 대화 유지,
  지우기, `localStorage`에 아무것도 쓰지 않음.
- 화면 확인: 라이트·다크 둘 다, 파동 전환.
